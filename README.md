## 🎯 วิธีการใช้หลักสูตร

1. **เริ่มจาก Part 001** และทำตามลำดับ
2. **ทำ Workshop** ในแต่ละ Part
3. **สร้าง Project** ตามที่แนะนำ
4. **ฝึกฝน** เป็นประจำทุกวัน

## 📋 Prerequisites

- ความรู้พื้นฐาน JavaScript
- ความรู้ HTML/CSS (พอช่วยได้)
- Computer: Mac/Windows/Linux
- Node.js version 18+

## 🛠 Tools ที่ใช้

- **VS Code** - Editor
- **React Native CLI** หรือ **Expo CLI**
- **Android Studio** - Android Development
- **Xcode** - iOS Development (Mac only)
- **Git** - Version Control
